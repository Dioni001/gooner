## Sobre el nombre

Sí, el nombre suena raro. No, no es lo que estás pensando.

*Gooner* es el **gemelo de [Helper](https://github.com/Dioni001/Helper)**, ese que la familia mantiene oculto en el sótano. Helper es el hermano ordenado: README serio, módulos con documentación y advertencia ética. Gooner es el otro. Su nombre termina en *-er* igual que el de su hermano, pero con el sentido opuesto: *helper* ayuda, *goon* no ayuda a nadie.

El nombre se eligió entre el creador y un amigo, por unanimidad (dos votos de dos).

Aquí no hay contenido adulto de ningún tipo, solo programas inofensivos y bastante inútiles.

## Nota de privacidad

`BongoMan` escucha el teclado de forma global para poder animar al personaje mientras juegas o usas otras aplicaciones. No guarda, registra ni envía nada. El código está completo en este repositorio por si quieres comprobarlo.

Por esa misma razón, algún antivirus o Windows SmartScreen puede mostrar un aviso al ejecutarlo. Si te preocupa, compílalo tú mismo.
